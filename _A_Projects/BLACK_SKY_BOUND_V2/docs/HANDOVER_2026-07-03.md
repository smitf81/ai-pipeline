# Handover — 2026-07-03

## Plain-English state

Black Sky Bound V2 is no longer an RTS prototype and no longer a Canvas 2D husk. It is a WebGL-only, asset-light, top-down young-dragon action-survival prototype.

The scene has real atmosphere now: dark forest, torch pools, smoke, napalm, moonlight, shadows, raiders, husks, werewolves, and a grounded wyvern player. The visual direction has potential, but the game still needs stronger playable-loop and UX completion before more clever rendering work is justified.

## Current production fear to respect

The main risk is not lack of ideas. The main risk is never finishing.

Do not use the next phase to chase:

- full 2.5D actor/scenery height layering;
- AI-generated art tooling;
- spritesheet pipelines;
- a deeper renderer rewrite;
- editor/tool integration;
- RTS/base/economy systems;
- open-ended atmospheric experiments.

Those can become future products or future-game tech. They are not needed to prove this first game can ship.

## What recently landed

### Runtime and map publication

- Standalone BSB now loads the AXIOM-baked First Escape / First Flightless Night runtime map through `data/maps/manifest.json`.
- Default browser boot no longer silently uses the built-in demo map.
- The live map has been expanded to 80x60 through the AXIOM centre-growth path and BSB loads it with explicit manifest/default provenance.

### Player creature and combat feel

- The grounded wyvern projection now keeps head, torso, limbs, and tail connected through lunges, claw attacks, and dodges.
- Completed actions and dodges have visual recovery without adding extra gameplay contact or displacement.
- Stamina, sprint, and dodge are live for the player; raider/werewolf evasion is bounded and stamina-limited.

### Enemies and encounter foundation

- Raiders, husks, and werewolves have distinct pressure/combat profiles.
- Raiders can carry torches and alternate spear/torch attacks.
- Torch ownership, enemy attack windups, and death/aftermath projections are renderer-neutral rather than hardcoded view hacks.

### WebGL visual stack

- WebGL is the only supported runtime renderer.
- Current visual stack includes terrain, scene objects, actor projections, darkness/light influence, smoke/fog scatter, napalm pools, SDF scene-object shadows, HUD/debug overlay, ambient particles, material profiles, and central post-process ownership.
- Actor Light-Silhouette Readability v0 was implemented and passed technically, but changed only about 0.099% of the frame. It is too subtle to materially improve human readability in the live scene.

## Honest visual verdict

The current visual presence is promising but not yet commercially sharp.

Strengths:

- strong night-forest mood;
- believable torch/local-light direction;
- asset-light primitive approach has a distinctive identity;
- scene no longer feels like plain coder-art dots.

Weaknesses:

- gameplay readability is still not strong enough;
- actors can disappear into the light/smoke/forest soup;
- tree trunks still risk reading like debug/UI bars;
- tiny rim/catchlight changes are swallowed by the low-value scene;
- better results likely require either atmosphere tuning or a future fake-height/depth model.

Decision:

> Park 2.5D height/layer work until a later game or a post-release upgrade. For this game, improve readability through simpler silhouettes, better atmosphere, UI/UX clarity, and controlled scene composition.
