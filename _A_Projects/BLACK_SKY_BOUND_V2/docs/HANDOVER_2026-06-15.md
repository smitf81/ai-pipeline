# End-of-Day Handover — 2026-06-15

## Current project state

Black Sky Bound v2 has been re-anchored around the new `GCD.md`:

- top-down 2D young-dragon action survival;
- tooth, claw, smoke, speed, enemy pressure, and escape;
- dragonfire is a later payoff, not a starting tool;
- no RTS economy, base-building, strategy control, morale, full stealth, full flight, or complex fire sim for first playable.

The project is no longer intended to preserve old RTS behaviour. The old husk is now only useful as a small browser/canvas technical skeleton.

## What landed today

### 1. GCD anchor

Created the focused Game Concept Document and placed it at `GCD.md`.

### 2. Dragon-survival pivot

Pivoted the stripped prototype into a first-playable direction:

- controllable young dragon;
- tooth/claw attack;
- body lunge;
- smoke disruption;
- raider, husk, and werewolf pressure enemies;
- escape-zone win condition;
- HP/loss state;
- preserved 16-mask terrain blob painting.

### 3. Documentation clean-up

Removed stale RTS handover/docs that could confuse later agent passes. Current documentation is intentionally lean.

### 4. ECS foundation v1

Refactored gameplay into a lightweight Entity Component System:

- entities are IDs;
- components are runtime data;
- systems own behaviour;
- interfaces are capability contracts based on required components;
- enum-like constants replace loose strings;
- actor/ability/scenario values are data-driven.

Key directories:

- `src/ecs/`
- `src/constants/`
- `src/components/`
- `src/data/`
- `src/systems/`
- `src/game/`

### 5. Launcher wrapper

Added easy boot files:

- `LAUNCH_BSB.bat`
- `LAUNCH_BSB.ps1`
- `tools/launch.mjs`

The launcher starts a local Node server and opens the game browser page.
