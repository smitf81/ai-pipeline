AXIOM Launcher v1.2 Hotfix

This version avoids npm install during normal launch.
The bundle includes node_modules already, so the launcher validates Express and starts the server directly.

Use:
1. Extract/copy this whole axiom-launcher-bundle folder over the old one.
2. Run Install Desktop Shortcut.cmd again if you moved the folder.
3. Double-click AXIOM Launcher.

Only use AXIOM-Repair-Dependencies.cmd if node_modules is missing or broken.
