# AXIOM Agentic Repair Loop v0

## Purpose
Define AXIOM's bounded try/validate/retry workflow for plugin repair, editor capability gaps, and tool-gap proposals.

For package-level cognitive routing, use `brain/skills/cognitive-skill-kernel/SKILL.md` before choosing a repair/planning posture.

For the working philosophy behind bold try/validate/retry loops, use `brain/skills/fail-loud-output-loop/SKILL.md`: fail early, fail loudly, register the miss, and never let fallback or generated proposal output masquerade as activated AXIOM truth.

For requests where the literal repair may miss the real goal, use `brain/skills/negative-space-intent-reasoning/SKILL.md` before scoping. Example: "load this project into AXIOM" may require both import/discovery and viewport instantiation to satisfy the user.
